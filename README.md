# Albion Refine Profit (Asia)

ตัวช่วยคำนวณกำไรการ **Refine** ใน Albion Online เซิร์ฟ **Asia (East)** บอกว่าควรซื้อวัตถุดิบจากเมืองไหน Refine ที่เมืองไหน ขายที่ไหน และได้กำไรเท่าไหร่ พร้อมกราฟราคาย้อนหลัง

ราคาทั้งหมดมาจาก [Albion Online Data Project](https://www.albion-online-data.com/) (AODP) ซึ่งเป็นข้อมูลที่ผู้เล่นช่วยกันส่งเข้าไป

---

## เริ่มใช้งาน (Windows)

1. กดปุ่ม **Code → Download ZIP** ที่หน้านี้ แล้วแตกไฟล์ไว้ที่ไหนก็ได้
2. ดับเบิลคลิก **`start.bat`** หน้าต่างดำจะเปิดขึ้น แล้วเบราว์เซอร์จะเปิดเว็บที่ `http://localhost:8777/` ให้เอง
3. เลิกใช้แล้วปิดหน้าต่างดำได้เลย

ไม่ต้องติดตั้งโปรแกรมเพิ่ม เพราะใช้ PowerShell ที่มากับ Windows

> ดับเบิลคลิก `index.html` ตรงๆ จะใช้ไม่ได้ เบราว์เซอร์ไม่ยอมให้หน้าเว็บอ่านไฟล์ข้อมูลเมื่อเปิดแบบนั้น ต้องเปิดผ่าน `start.bat`

### ตั้งค่าครั้งแรก (แท็บ "ตั้งค่าผู้เล่น")

- **Daily bonus ของวันนี้**: จำเป็น ต้องใส่ทุกวัน
- **ค่าใช้สถานี Refine**: จำเป็น ใส่ของเมืองที่คุณใช้ (silver ต่อ 100 Nutrition ตามที่เห็นในเกม)
- **Premium**: ติ๊กถ้าเป็น Premium (ภาษีขาย 4% แทน 8%)
- **Spec การ Refine**: ไม่บังคับ ใช้ประมาณจำนวน Focus

การตั้งค่าทั้งหมดเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น ถ้าเปลี่ยนเบราว์เซอร์ต้องตั้งค่าใหม่

## แต่ละแท็บทำอะไร

| แท็บ | ใช้ทำอะไร |
|---|---|
| **ภาพรวมกำไร** | วัตถุดิบ Refine ทุกตัว (T2–T8 รวม Enchant .1–.4) เรียงจากกำไรมากไปน้อย กรองตามวัตถุดิบ Tier และ Enchant ได้ |
| **คำนวณรายไอเทม** | บอกว่าซื้ออะไรที่เมืองไหน ต้องซื้อกี่ชิ้น RRR ค่าสถานี ขายที่ไหน ขายได้วันละกี่ชิ้น และกำไรต่อ 1 Focus |
| **ราคา & กราฟ** | ราคาปัจจุบันทุกเมือง กับกราฟราคาเฉลี่ยรายวันย้อนหลังสูงสุด 30 วัน |
| **อัปเดตราคา** | รายการไอเทมที่ราคาเก่าเกิน 10 นาที / 30 นาที / 1 ชั่วโมง หรือยังไม่มีข้อมูล แยกตามเมือง เอาไว้เดินไปเปิดตลาดอัปเดตเองในเกม |

### กฎที่บังคับไว้

- **Daily bonus**: ถ้ายังไม่ใส่ จะขึ้นแถบแดงและคำนวณไม่ได้ วันใหม่เริ่ม 06:00 เวลาไทย (รอบ maintenance ของเซิร์ฟ Asia) แล้วระบบจะถามใหม่ ข้อมูลที่เก่ากว่า 7 วันลบทิ้งอัตโนมัติ
- **ค่าสถานี**: เมืองที่ยังไม่ใส่ค่าสถานีจะไม่ถูกนำมาคำนวณ

## ทำให้ราคาสดขึ้น

ราคาจะสดได้ ก็ต่อเมื่อมีคนเปิดดูตลาดในเกมพร้อมรันโปรแกรมเก็บราคา

1. ดาวน์โหลดและรัน [Albion Data Client](https://www.albion-online-data.com/client) ระหว่างเล่น
2. เปิดแท็บ **อัปเดตราคา** แล้วเลือกเงื่อนไข เช่น "เกิน 30 นาที" และเมืองที่คุณอยู่
3. คลิกชื่อไอเทมเพื่อคัดลอก ไปวางค้นในตลาดในเกม แล้วเปิดดูทีละตัว
4. เปิดแท็บนี้ค้างไว้ เว็บจะดึงราคาใหม่ทุก 1 นาที ไอเทมที่อัปเดตแล้วจะหายจากรายการเอง

## แก้ปัญหา

**กด "ดึงราคาล่าสุด" แล้วขึ้นเตือนสีส้มว่า API จำกัดจำนวนครั้ง**
API ฟรีของ AODP จำกัดจำนวนครั้งที่เรียกต่อ IP รอประมาณ 2 นาทีแล้วระบบจะลองใหม่เอง

**เปิดดูราคาในเกมแล้ว แต่ไอเทมนั้นยังไม่อัปเดต**
- เช็กหน้าต่าง Albion Data Client ว่าขึ้น `Successfully sent ingest request`
- ดูว่า client รู้ตำแหน่งถูกเมืองไหม เช่น Lymhurst ต้องขึ้น `Updating player location to 1002` ถ้าขึ้นรหัสแปลกๆ ให้ออกจากเมืองแล้วเข้าใหม่ หรือปิดเปิด client ใหม่ แล้วค่อยเปิดตลาดอีกรอบ
- รอ 1–2 นาทีแล้วกด "ดึงราคาล่าสุด" ถ้ายังไม่ขึ้น แปลว่าข้อมูลไม่ได้เข้า AODP เว็บนี้แสดงได้เฉพาะสิ่งที่ AODP มี

**หน้าต่างดำของ `start.bat` ปิดไปเองหรือขึ้น error**
พอร์ต 8777–8787 อาจถูกโปรแกรมอื่นใช้อยู่ หรือเครื่องบล็อกการรันสคริปต์ PowerShell ถ่ายภาพข้อความ error ไว้เพื่อหาสาเหตุ

## สูตรที่ใช้คำนวณ

- **RRR** (วัตถุดิบที่ได้คืน) = 1 − 1 / (1 + Production bonus)
  - Production bonus = 18% (ฐาน) + 40% (ถ้าเป็นเมืองโบนัสของวัตถุดิบนั้น) + 59% (ถ้าใช้ Focus) + Daily bonus (10% หรือ 20%)
  - เมืองโบนัส: Fort Sterling = ไม้, Lymhurst = ใย, Bridgewatch = หิน, Martlock = หนัง, Thetford = แร่
- **ต้นทุนต่อชิ้น** = ราคาวัตถุดิบรวม × (1 − RRR) + ค่าสถานี
- **ค่าสถานีต่อชิ้น** = Item value × 0.1125 × (ค่าสถานีที่ใส่ ÷ 100)
- **ได้สุทธิเมื่อขาย** = ราคา × (1 − ภาษี − setup fee 2.5% ถ้าตั้ง Sell order) ภาษี 4% สำหรับ Premium, 8% สำหรับไม่ Premium
- **กรองราคาผิดปกติ**: ราคาที่ต่างจากค่ากลางของทุกเมืองเกิน 2.5 เท่าจะไม่ถูกเลือกเป็นจุดซื้อหรือขาย
- **ราคาที่เก่ากว่า 48 ชั่วโมง** จะไม่ถูกนำมาคำนวณ
- **Focus จาก Spec** เป็นค่าประมาณ ถ้าไม่ตรงกับในเกม ให้กรอก Focus จริงในหน้าคำนวณแทน

ตัวเลขทั้งหมดแก้ได้ใน `data/config.json` ถ้าเกมอัปเดต

## โครงสร้างไฟล์

```
start.bat                  ดับเบิลคลิกเพื่อเปิดใช้งาน
serve.ps1                  เว็บเซิร์ฟเวอร์เล็กๆ ที่ start.bat เรียกใช้
index.html                 หน้าเว็บ
assets/app.js              ตรรกะการคำนวณทั้งหมด
assets/style.css           หน้าตา
data/config.json           ตัวเลขของเกม (ภาษี, โบนัสเมือง, RRR, เวลารีเซ็ต)
data/recipes.json          สูตร Refine จากไฟล์ข้อมูลเกม (ao-bin-dumps)
data/prices.json           ราคาสำรอง ใช้ตอนดึงราคาสดไม่ได้
data/history.json          ประวัติราคาที่เก็บเอง
scripts/update-prices.mjs  สคริปต์ดึงราคาไปเก็บใน data/ (ไม่บังคับ ต้องมี Node.js)
.github/workflows/         ตั้งเวลาให้ GitHub รันสคริปต์ด้านบนอัตโนมัติ (ไม่บังคับ)
```
